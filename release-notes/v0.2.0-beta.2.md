The second test version of BookHeart 0.2. If you're on 0.2.0-beta.1 with test versions turned on, BookHeart should offer you this one by itself.

## What's changed since beta 1

- **F1 opens the user manual.** The list of keyboard shortcuts is still in the Help menu, under Keyboard shortcuts.
- **Tab no longer goes into the menu bar.** It moves between the things on the screen, and Alt or F10 opens the menus, as in other Windows programs. This had been wrong since the first version.

## Testing the updater

If this version reached you through the update dialog, the updater works. Please say how it went: whether the dialog read well with your screen reader, whether the download progress was announced, and whether BookHeart reopened on your book afterwards.
