A test version of StoryHeart 0.2.

## What's new

- This list is all you'll see in the update window now: just the changes, one per line, with nothing repeated. Use the arrow keys to read through them.
- In any list, type the first letters of a title to jump to it.
- Tabbing into a list lands on the item that's selected, not the first one.
- Settings and Book settings are divided into named sections, and your screen reader says each section's name as you move into it.
- StoryHeart remembers the size and position of its window, and whether it was maximised.
- On the position slider, Home and End no longer jump straight to the start or end. The first press tells you what will happen, and you press it again to go.
- Drop-down lists match the light or dark colours instead of always being white.
- Sharper text.
- Hovering the mouse over a button shows what it does and its shortcut.
- StoryHeart now runs on .NET 10, the newest version of the system it's built on. You don't need to install anything.
- The licence agreement explains more clearly that StoryHeart's code is published to read, not to copy or reuse, and now shows the date it was last updated.

## Testing

After updating, please try: typing a letter in the library, tabbing into a list, Home on the position slider, closing and reopening StoryHeart to check its window comes back the same, and opening Settings to hear the section names. The update window for the next version will show the new list of changes.
