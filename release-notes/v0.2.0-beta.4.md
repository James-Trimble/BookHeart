The fourth test version of BookHeart 0.2.

## What's changed since beta 3

- **Arrow keys no longer jump between controls.** Pressing Up from the Pause button used to land on the position slider, where the next arrow press moved your place in the book. Now the arrows only work inside the thing you're on (lists, menus, the Chapters and Bookmarks tabs, sliders and drop-downs), and Tab moves between controls, as in other Windows programs. The same goes for every dialog.

## Testing the updater

This is the first update that uses beta 3's improved updater. After you choose Install now, BookHeart should close, install, open again by itself on the screen you were on, and say "BookHeart has been updated to version 0.2.0-beta.4". Please try it from the library, and if you can, once with a book open.
