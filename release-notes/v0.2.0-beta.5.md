A test version of BookHeart 0.2.

## What's new

- Arrow keys no longer move you from one button to another. On a button, the arrow keys now do nothing, and Tab moves between controls, as in other Windows programs. Lists, sliders, drop-down lists and tabs still use the arrow keys as before.
- This "What's new" text is easier to read: each change is its own paragraph, with no bullet symbols for your screen reader to read out.
