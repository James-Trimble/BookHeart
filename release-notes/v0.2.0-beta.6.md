A test version of StoryHeart 0.2. BookHeart has a new name: it's now called StoryHeart.

## What's new

- The program, its window, the installer, the Start menu, the manual and the website links all say StoryHeart now.
- A new icon: the same book and heart, with sound waves coming from the heart.
- Your books, places, bookmarks and settings come with you. The first time StoryHeart opens, it moves them from the BookHeart folder to a StoryHeart one.
- StoryHeart is installed in a StoryHeart folder, and the old BookHeart folder, shortcuts and Open with entries are removed. If you had a BookHeart desktop shortcut, you get a StoryHeart one instead.

## Testing the update

Please update the usual way. StoryHeart should close, install, open again by itself and say it has been updated to version 0.2.0-beta.6. Then check that:

- your books are all there, with your places and bookmarks;
- the Start menu, and the desktop if you had a shortcut there, say StoryHeart and not BookHeart;
- double-clicking a .m4b file opens StoryHeart, if you'd set that up before.

If you use the portable copy, it can't update itself this once. Download StoryHeart-0.2.0-beta.6-Portable.zip and unzip it into the same folder that holds your BookHeart folder; it brings your library over the first time it opens.
