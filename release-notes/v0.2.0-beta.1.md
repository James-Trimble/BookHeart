A test version of BookHeart 0.2, for trying out automatic updates.

## What's new

- **BookHeart keeps itself up to date.** It checks for a new version when it starts and once a day. When there is one, it tells you what's new and offers **Install now**, **Remind me later** and **Skip this version**. It waits until you pause rather than interrupting a book. You can also check from Help → Check for updates.
- **New shortcuts.** Alt+Left and Alt+Right skip back and forward. Ctrl+Left and Ctrl+Right change chapter. Ctrl+Up and Ctrl+Down make it faster and slower. (Alt+Comma, Alt+Period, Ctrl+[ and Ctrl+] are gone.)
- **Settings → Updates** lets you turn automatic checks off, or choose to get test versions like this one.

## For testers

This version can't update itself from 0.1, so install it by hand. After that, turn on **Include test versions** in Settings → Updates, and the next test version should be offered to you automatically.
