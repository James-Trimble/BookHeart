A small update to BookHeart 0.1.

## What's changed

- The installer now shows the BookHeart licence agreement, which you accept before installing. You can read it again from Help → Licence agreement.
- Help → Third-party notices lists the open-source components BookHeart uses, along with their licences.
- The About box says who BookHeart is by and under what terms.
- The user manual now comes with BookHeart. Open it from Help → User manual, or from the Start menu.

## Downloads

- **BookHeart-0.1.1-Setup.exe** installs BookHeart. If you already have 0.1.0 installed, run this and it will update it. Your library is kept.
- **BookHeart-0.1.1-Portable.zip** doesn't install anything. To update a portable copy, replace the files with the new ones and keep your `Data` folder.

Windows 10 (version 1809) or later, 64-bit.
