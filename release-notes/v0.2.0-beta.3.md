The third test version of BookHeart 0.2.

## What's changed since beta 2

- **BookHeart reopens itself after an update.** It now starts a small helper that waits for the installer to finish and then opens BookHeart, rather than relying on the installer alone.
- **It tells you it was updated, every time.** BookHeart remembers which version it last ran, so the first time a newer version opens it says "BookHeart has been updated to version…", however it was opened.
- **It comes back to where you were.** After an update you're on the same screen as before: the library, or your book if you had one open.

## Testing

Updating from beta 2 to this version uses beta 2's updater, which may not reopen BookHeart by itself. If it doesn't, open it yourself: it should still tell you it was updated. The reopening fix will show on the next update after this one.
