# Roadmap

These are ideas, not promises. StoryHeart is very new, and anything here can change, move, or be dropped at any time. Nothing has a date.

## Next test version (0.2.0-beta.8)

- Fixes for anything found while testing beta.7.
- **Book details from the files**: title, author, narrator, series and cover art, read from the audiobook itself, with the file name used when a file has none. Shown and searchable in the library, read out by Alt+I, and shown in Windows' media controls. The cover is shown on screen once a sighted tester can check how it looks.
- **Keep listening while an update downloads.** It downloads in the background. When it's done, your book pauses and a "Download complete" dialog offers Install now or Later. Choosing Later carries on with your book, and the update installs by itself when you next close StoryHeart. If nothing is playing, the dialog just opens.
- **Changes to the licence agreement shown once.** StoryHeart notices when the agreement's "Last updated" date changes and shows it to you. A portable copy shows the agreement the first time it runs.

## Before the first public release

- **A website**, with a home page, downloads, the manual, a privacy page and a way to donate (Ko-fi or GitHub Sponsors).
- **Feedback from inside the program**, sent to a feedback email address on the website's domain.
- **Changes to the privacy policy** shown when you next open StoryHeart, once there is a privacy page on the website.
- **Cover art on screen**, in the library and while a book plays.
- **Signing**, so Windows stops warning that StoryHeart is from an unknown publisher.
- **A sighted tester**, to check how StoryHeart looks and point out anything odd.
- **Decide whether the code stays public**, or moves to a private repository with only the releases public.

## Later

- Sound cues, for things like reaching a bookmark or the end of a chapter.
- A sleep timer.
- **Show what you're listening to on Discord**, if you turn it on: "Listening to StoryHeart", with the book's title, or just "an audiobook" if you'd rather keep that private.
- StoryHeart in more languages, starting in your Windows language.
- A version that plays in a web browser.
