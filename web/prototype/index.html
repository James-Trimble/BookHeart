          Resuming books

          Browsers do not let a page reopen a file on your computer by itself. By default, choosing a recent book asks you to pick the same file again (or all the files of a set), and it then starts at your saved place. To skip that step, keep a copy of each book inside this browser.

          Each saved book uses storage equal to its file size. The copy stays on this computer.

          Keyboard shortcuts

          These work anywhere on the page. All controls are also ordinary buttons you can Tab to.

          Alt + P
          Play or pause
          Alt + ,
          Skip back
          Alt + .
          Skip forward
          Alt + Up arrow
          Volume up
          Alt + Down arrow
          Volume down
          Alt + B
          Add a bookmark at the current spot
          Alt + I
          Hear where you are in the book
          Alt + R
          Resume the book you listened to most recently
          Alt + O
          Open a new book

          Headphone and keyboard media keys also play, pause and skip.
